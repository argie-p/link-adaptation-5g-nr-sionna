# Κώδικας της διπλωματικής εργασίας

**«Προσαρμογή Ζεύξης για Δίκτυα 5G NR με χρήση του NVIDIA Sionna»**, Αργύρης Πάντζιος, Πανεπιστήμιο Θεσσαλίας.

Τα αρχεία αναπαράγουν τα σχήματα, τους πίνακες και τους αριθμούς των Κεφαλαίων 3 και 4. Κάθε αρχείο τρέχει μόνο του και γράφει στην αρχή του τι αναπαράγει, πώς και σε πόσο χρόνο. Περιλαμβάνεται μόνο κώδικας που παράγει κάποιο αποτέλεσμα της εργασίας. Οι δοκιμές που έγιναν για να επιλεγεί η πορεία της μελέτης δεν περιλαμβάνονται.

## Εγκατάσταση

```
git clone https://github.com/argie-p/link-adaptation-5g-nr-sionna.git
```

Χρειάζεται Python 3.10 ή νεότερη. Τα δύο κεφάλαια θέλουν διαφορετική έκδοση του Sionna, οπότε καλύτερα σε χωριστά περιβάλλοντα.

```
pip install sionna==2.2.0      # Κεφ. 4 (στην εργασία: sionna-rt 2.2.0, mitsuba 3.9.1, drjit 1.5.0)
pip install sionna==2.0.1      # Κεφ. 3 (για το k3_2: sionna==2.1.0)
```

Τα αποτελέσματα της εργασίας παράχθηκαν στο Google Colab, με GPU NVIDIA T4 και PyTorch 2.11. Τα αρχεία του Κεφ. 3 τρέχουν και με το Sionna 2.2.0, με μικρές διαφορές στα νούμερα.

Ο κώδικας του SALAD είναι των δημιουργών του (https://github.com/NVlabs/salad) και δεν περιλαμβάνεται εδώ. Τα αρχεία του Κεφ. 4 τον κατεβάζουν αυτόματα με git, στο commit 2746947 που χρησιμοποιήθηκε στην εργασία.

## Πώς τρέχουν

```
python k4_2_main.py
```

Κάθε αρχείο του Κεφ. 4 γράφει τα αποτελέσματά του στον φάκελο `results/` και τα σχήματα στον φάκελο `figures/`. Οι φάκελοι αλλάζουν με τις μεταβλητές περιβάλλοντος `RESULTS_DIR`, `FIG_DIR` και `SALAD_DIR`.

Τα k4_2_sensitivity, k4_2_main, k4_3_routes και k4_4_speed_compression είναι ανεξάρτητα μεταξύ τους. Οι καλύτερες ρυθμίσεις που επιλέγει το k4_2_sensitivity είναι ήδη γραμμένες στα υπόλοιπα. Αν μια εκτέλεση διακοπεί, την επόμενη φορά συνεχίζει από εκεί που σταμάτησε. Το k4_figures.py τρέχει στο τέλος και χρειάζεται τουλάχιστον το results/main.csv. Το k4_4_speed_compression.py με το όρισμα `compressed` τρέχει μόνο τον συμπιεσμένο χρόνο (περίπου 15 λεπτά).

Στο Google Colab: runtime με GPU, `!pip install sionna==2.2.0`, ανέβασμα των αρχείων και `!python k4_2_main.py`. Για να μη χαθούν τα αποτελέσματα σε αποσύνδεση, ο φάκελος των αποτελεσμάτων μπορεί να είναι στο Google Drive, π.χ. `%env RESULTS_DIR=/content/drive/MyDrive/results`.

## Τα αρχεία των αποτελεσμάτων

Κάθε γραμμή των results/*.csv είναι μία εκτέλεση:

| Στήλη | Περιεχόμενο |
|---|---|
| key | όνομα της εκτέλεσης, ίδιο με το αρχείο results/hist/key.npz |
| freq, y0, spp, kmh, mode | συχνότητα, αρχή της διαδρομής [m], slots ανά θέση, ταχύτητα [km/h], realistic ή compressed |
| seed | σπόρος |
| mech, delta, lr, probe, rho, ke, aw | μηχανισμός και ρυθμίσεις: βήμα του OLLA [dB], παράμετροι του SALAD, anti-windup |
| SE, BLER | μέση φασματική απόδοση [bits/s/Hz] και BLER [%] |
| SE_after30, BLER_after30 | τα ίδια χωρίς τις πρώτες 30 θέσεις της διαδρομής |
| clipped, probes | μόνο SALAD: % slots με τον στιγμιαίο στόχο BLER στο κάτω όριο, πλήθος probes |

Τα αρχεία results/hist/*.npz έχουν τις τιμές ανά slot: se, harq (1 ACK, 0 NACK, −1 χωρίς μετάδοση), mcs, sinr και, για το SALAD, tau (στιγμιαίος στόχος BLER), probe, integ (αθροιστής του ελεγκτή) και est (εκτίμηση SINR).

## Αναπαραγωγιμότητα

- **Σπόροι.** Οι συγκρίσεις γίνονται με τους σπόρους 42, 1, 7, 123 και 2024 και οι ρυθμίσεις επιλέγονται με τον σπόρο 99. Σε κάθε εκτέλεση οι σπόροι του NumPy, του PyTorch και του Sionna ορίζονται ξανά με σταθερή σειρά, οπότε όλοι οι μηχανισμοί ενός σπόρου βλέπουν το ίδιο σφάλμα στην αναφορά SINR.
- **GPU και CPU.** Σε CPU οι τυχαίοι αριθμοί είναι άλλοι και το ray tracing δίνει ελάχιστα διαφορετικά κανάλια. Τα νούμερα αλλάζουν λίγο, τα συμπεράσματα όχι. Για τα ακριβή νούμερα της εργασίας χρειάζεται GPU.
- **torch.compile.** Τα k3_2, k3_5 και k3_7 χρησιμοποιούν torch.compile, όπως τα tutorials. Ο μεταγλωττισμένος κώδικας παράγει τυχαίους αριθμούς με άλλη σειρά, οπότε χωρίς αυτό τα αποτελέσματα των k3_2 και k3_7 αλλάζουν ελαφρά.
- **Σπόροι των Σχημάτων 20 και 22.** Ό,τι υπολογίζεται από τις τιμές ανά slot της κύριας διαδρομής (Σχήματα 20 και 22, πίνακες ανά τμήμα της διαδρομής και οι σχετικοί αριθμοί του κειμένου) χρησιμοποιεί τους σπόρους 1, 7, 123 και 2024, όπως στην εργασία. Αλλάζει με τη μεταβλητή SEG_SEEDS του k4_figures.py.
- **Αριθμοί του κειμένου.** Οι αριθμοί που αναφέρει το κείμενο του Κεφ. 4 και δεν βρίσκονται σε πίνακα (π.χ. η μεταβολή του SINR ανά χρονοθυρίδα σε κάθε τμήμα ή οι αποκοπές κάθε διαδρομής) τυπώνονται στο τέλος του figures/tables_k4.md.
